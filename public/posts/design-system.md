Designing an appealing User Interface is crucial for capturing the user's attention. Minimalist dark modes have become a staple in modern web applications because they are easier on the eyes and establish a sleek, premium, professional vibe.

### Key Features Used:
- **Glassmorphism**: Semi-transparent backgrounds with background-blur that interact with light and geometry underneath.
- **Dynamic Micro-interactions**: Hover effects on cards that translate slightly and display a glowing box-shadow for depth.
- **Modern Typography**: Inter variable font configuration for seamless reading scales.
